## 🚀 项目实践

- **[Pi Native CRM](https://github.com/Yzzz88/yzzz-crm)** — Agent 原生 CRM 工作台，以真实 CRM 状态空间承载 Agent 行动；包含受控执行 Harness、多 Agent 与商机 Mission、知识记忆闭环，以及 Trace / Eval 可观测性。
- **Memory 与知识** — 集成本地 RAG、WeKnora Wiki、Mem0；记忆候选带原文证据，支持负责人确认、改写、驳回、有效期与替换。
- **可靠执行** — 工具权限和组织范围控制、人工审批、暂停/恢复/取消、执行租约、重试与累计预算。
- **Eval 与 Trace** — 确定性检查、语义评审和回归样例；Langfuse 记录 Trace、用量与 Eval 分数。
